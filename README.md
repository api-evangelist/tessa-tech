TESSA Marketing & Technology is a McLean, Virginia digital marketing and web development agency (est. 2012) selling SEO, paid search and social advertising, generative engine optimization, WordPress and custom web/app development, WCAG 2.2 AA accessibility audits, AI website search and avatars, and an AI Agent Readiness service. It publishes an unusually complete agent surface for a services firm: an A2A agent card (protocolVersion 0.3.0, nine skills) and JSON-RPC endpoint on aiagent.tessa.tech, an anonymous hosted MCP server (Streamable HTTP, ten tools with published inputSchema) advertised through an MCP server.json and a did:web document, a 28-card per-service A2A fleet, a FastAPI OpenAPI for the directory service behind it, RFC 8414/9728 OAuth discovery for a second OAuth 2.1-gated WordPress MCP server, llms.txt, a Markdown pricing twin, and an AI-welcoming robots.txt. TESSA also operates two vertical A2A registries, complianceregistry.net and marketingregistry.org.

**Areas:** Digital Marketing · SEO · Web Development · Accessibility · AI Agent Readiness · Professional Services · Agent Directory · A2A · MCP · Agent-Native · Company

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).
